Política de privacidad

Última actualización: 20 de octubre de 2026.

1. Responsable

ENCI es un asistente de atención desarrollado por Nicolás Calmels. Para consultas sobre privacidad o datos personales, escribí a hola@hermanoscalmels.com.

2. Información que puede tratarse

Según las funciones habilitadas y el canal utilizado, ENCI puede procesar el contenido de los mensajes que enviás, tu número o identificador de contacto, nombre o datos que incluyas voluntariamente, y datos técnicos o registros necesarios para operar, mantener y proteger el servicio. Evitá enviar contraseñas, datos de pago u otra información sensible que no sea necesaria.

3. Finalidades

La información se utiliza para responder consultas, brindar atención, mantener el contexto necesario de una conversación, mejorar la calidad y seguridad del servicio, y resolver problemas técnicos o abusos.

4. Proveedores y transferencias

Para funcionar, ENCI puede apoyarse en proveedores tecnológicos de mensajería, automatización y procesamiento de inteligencia artificial, como Meta/WhatsApp, n8n y Google/Gemini, según la configuración activa. Estos proveedores pueden tratar información para prestar sus servicios conforme a sus propias condiciones y políticas. El procesamiento puede realizarse en servidores ubicados en otros países.

5. Conservación y seguridad

Los datos se conservan únicamente durante el tiempo necesario para las finalidades indicadas, atender solicitudes y cumplir obligaciones aplicables. Se aplican medidas razonables para limitar el acceso y proteger la información; ningún sistema puede garantizar seguridad absoluta. Los registros de proveedores externos pueden tener sus propios plazos de conservación.

6. Tus opciones y derechos

Podés solicitar acceso, corrección o eliminación de tus datos personales y realizar consultas sobre su tratamiento, sujeto a las verificaciones y excepciones legales que correspondan. Para solicitar la eliminación, visitá la página de eliminación de datos o escribí al correo indicado.

7. Menores

ENCI no está diseñado específicamente para recopilar datos de menores. Si creés que un menor proporcionó datos personales sin autorización adecuada, contactanos para revisar el caso.

8. Cambios

Esta política puede actualizarse cuando cambien las funciones, proveedores o requisitos aplicables. Publicaremos la versión vigente en esta URL.

9. Contacto

Para consultas relacionadas con esta política: hola@hermanoscalmels.com.

Esta información describe el funcionamiento previsto de ENCI y debe revisarse si cambia la configuración real de almacenamiento, los proveedores o los plazos de conservación.
